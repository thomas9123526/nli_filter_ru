Label Tool

Hand-label paragraphs for the policy labels

Open a file made by python nli_label.py sample … (for example labels\seed.jsonl). For each paragraph, answer every label Yes or No. The policy action (remove / keep / review / pass) is computed from your answers. Override it if the policy gets it wrong, and say why in the note.

Save writes the file back in place (Chrome / Edge), or downloads it (other browsers). Work is also kept in this browser between visits.

Keys: Enter done & next · j/k next/previous · n all unanswered = No · g gate Yes · G gate No (= pass) · Ctrl+S save
