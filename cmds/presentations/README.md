## Rebuild after changing a number or a text

The decks are generated by `build_decks.js` (pptxgenjs). Edit the text there, then:

```powershell
npm install pptxgenjs@3.12.0                  # once, in any folder (e.g. a temp folder)
$env:NODE_PATH = "<that folder>\node_modules"
node cmds\presentations\build_decks.js
```

Without `APPLY_THEME` the decks keep PowerPoint's default theme colours for theme-coloured shapes. The decks in this
folder were built with the theme applied (ink, teal, and one colour per action: remove rust, review amber, keep
green, pass grey).
