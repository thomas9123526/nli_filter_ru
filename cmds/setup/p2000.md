# The P2000 machine (Windows, Quadro P2000, i7 12th gen, 32 GB)

The Quadro P2000 is a Pascal GPU (2017, 5 GB). Current torch runs on it only as the `+cu126` build; the
`+cu128` build of the other machines no longer includes Pascal. The wheels are in
`pkgs\p2000-windows-torch-cu126` (torch for Python 3.10 and 3.12 + what torch needs, 4.9 GB); everything else
comes from the normal Windows folder.

Checked 2026-11-13 on the development PC: a fresh Python 3.10 venv installed only from these two folders
(no internet) has 53 packages without conflicts, passes the filter tests (61, including loading ModernBERT),
and the torch build is compiled for `sm_50 sm_60 sm_61 sm_70 sm_75 sm_80 sm_86 sm_90`; `sm_61` = Pascal
(P2000, GTX 10xx). Not tested on a real P2000.

## 1. Driver

Only the **NVIDIA driver**: Quadro P2000, **580 branch** (58x.xx) from nvidia.com. No CUDA toolkit, no cuDNN
(they are inside the torch wheel). Not newer than 58x: the next branches drop Pascal. Check with `nvidia-smi`:
"CUDA Version" must be 12.6 or higher. Also needed (most PCs have it): Microsoft Visual C++ Redistributable
2015-2022 x64.

## 2. Python packages (offline)

Python 3.10:

```powershell
cd <project folder>
py -3.10 -m venv .venv
.venv\Scripts\Activate.ps1
pip install --no-index --find-links pkgs\p2000-windows-torch-cu126 --find-links pkgs\rtx5090-windows-py310 torch==2.11.0+cu126 transformers==5.20.2 orjson pyahocorasick zstandard sentencepiece protobuf paramiko
```

Python 3.12: the same with `py -3.12` and `pkgs\windows-py312` as the second folder. Keep the project path
short (e.g. `D:\nli_filter2`).

```powershell
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
# expected: 2.11.0+cu126 True Quadro P2000
python .\nli_models.py --check modernbert --device cuda:0 --dtype fp32
```

## 3. Running on the P2000

Always `--dtype fp32` (fp16 is very slow on this chip; `auto` would pick fp16) and a moderate batch:

```powershell
python .\nli_filter.py test_germany.jsonl --country Germany --country-adj German --judge-model none --device cuda:0 --dtype fp32 --batch-size 16 --output-dir out_p2000
```

The summary's `pairs/s` is the real speed (estimate: 30-60 pairs/s with ModernBERT; the i7-8700K CPU did 3.4).
The 5 GB memory holds any of the three models in fp32 with `--batch-size` 8-16. On the CPU instead:
`--device cpu` (20 threads of the i7-12th gen, estimate 6-10 pairs/s).

The P2000 is for tests and the viewer; the 2 TB corpus belongs on the H200 (`cmds\h200\linux_h200.md`).
